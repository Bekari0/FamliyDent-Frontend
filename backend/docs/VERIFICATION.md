# Проверка реализации — 21 октября 2026

## Автоматические проверки

- TypeScript frontend/backend и production build проходят.
- 19 backend unit-тестов, 21 интеграционный тест и 3 frontend-теста.
- Интеграционные тесты используют отдельный MongoDB 8.0.17 replica set;
  рабочая база сайта в этих тестах не участвует.
- npm audit: 0 известных уязвимостей, включая dev-зависимости.
- Gitleaks: в файлах, подготовленных к коммиту, утечек не найдено.
- Конфигурации Compose и Caddy проверены их CLI.

## Проверенные границы

Проверены регистрация без повышения роли, отсутствие хешей паролей в ответах,
CSRF/Origin, защищённые production cookie, смена и обновление старых паролей,
отзыв сессий с защитой от одновременного входа, отключённые аккаунты, изоляция
заявок по пользователю и разделение полномочий staff/admin.

Проверены неизвестные поля и типы, невозможные даты, слишком большое тело,
ограничения запросов при поддельном X-Forwarded-For и хранение лимитов в MongoDB.
Скрытые файлы не обслуживаются frontend-сервером; URL медиа с паролем не публикуется.

Проверены атомарность заявки и outbox, откат после ошибки записи outbox,
идемпотентность, одновременные воркеры, временные/постоянные ошибки доставки,
восстановление просроченной аренды, ручной повтор с аудитом, подпись точных байтов,
повтор и конфликт bot eventId и защита завершённой заявки от устаревшего статуса.

Проверены оба AI-адаптера с контролируемым HTTP-ответом, запрет клиентского system
prompt/модели, требование сессии, постоянная квота, ограничение размера upstream
и отсутствие сырых ошибок внешнего сервиса в ответе клиенту.

Проверены публикация черновика, конфликт ревизии, аудит без снимка содержимого,
редактирование мигрированной записи с пустой биографией и корректное завершение
запуска при занятом порте без ложного сообщения о readiness.

## Рабочие данные и браузер

`db:verify` подтвердил валидаторы, индексы, документы и ссылки на медиа в
familydent_web: 182 записи контента, 87 медиа. Доступ пользователя приложения к
метаданным старой клинической FamilyDent отклонён сервером Atlas.
Smoke проверил readiness и все 18 типов контента, включая скомпилированный API
в production-режиме. Тестовые пользователи и заявки в рабочую БД не записывались;
чтение API штатно обновляет служебные счётчики лимитов.

В Chromium проверены главная, врачи, услуги, туризм и отзывы через Vite/API:
ошибок JavaScript и запросов API не обнаружено. На отдельной временной MongoDB
обе формы отправлены через настоящий браузер: каждая создала одну заявку и одно
outbox-событие, включая запись без необязательной услуги и даты.

## Границы проверки

Реальные bot/AI endpoint и секреты ещё не предоставлены. Их сетевое подключение
проверяется после настройки по документированному контракту; пока интеграции
отключены. Накопленные заявки сохраняются до включения бота.

Локально Docker Engine отсутствует: выполнена проверка конфигурации, но контейнеры
не запускались. В GitHub Actions добавлена отдельная сборка Docker image.
DNS, публичный TLS и фактическая публикация зависят от production-сервера и домена.
Отчёт фиксирует проведённые проверки и не является обещанием отсутствия любых
возможных уязвимостей.
