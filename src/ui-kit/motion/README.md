Skyro использует роли заголовков и текста с адаптивными размерами; на новых
страницах обнаружены семейства Retail и Poppins Skyro, на части остальных —
Retail Text и Circular. Для Family Dent сохранены собственные семейства,
палитра, размеры текста, переносы, интервалы и геометрия. Применён принцип
повторного использования ролей: наша типографика продолжает управляться
`tokens.css`, а движение получает отдельные токены в том же файле.

## Компоненты

```tsx
import { Reveal, RevealGroup, RevealItem, RevealHeading } from "@/ui-kit";
import { Link } from "react-router-dom";

<RevealHeading level={2} variant="heading-2">Наши услуги</RevealHeading>
<RevealGroup as="ul">
  <RevealItem as="li">Первая карточка</RevealItem>
  <RevealItem as="li">Вторая карточка</RevealItem>
</RevealGroup>
<Reveal as={Link} to="/services" className="existing-card">Подробнее</Reveal>
```

`Reveal` по умолчанию создаёт `div`. `as` сохраняет нужный тег либо компонент,
передающий `ref`, `className` и `style` своему DOM-элементу. `RevealHeading`
выводит настоящий `h1`…`h6` через общую типографику. Текст не дробится на буквы,
не дублируется и не меняет переносы. HTML-атрибуты, события и ARIA сохраняются.

`RevealGroup` задаёт только последовательность прямых дочерних `Reveal`;
сам контейнер не скрывается. Каждый элемент наблюдается отдельно. Очень длинная
сетка не требует попадания определённой доли всей своей высоты в экран.
Для блока, который уже анимируется целиком, дополнительное вложенное появление
обычно не нужно.

## Токены

Все значения находятся в `../tokens.css`:

- `--motion-reveal-duration` — длительность появления;
- `--motion-reveal-distance` — небольшое вертикальное смещение;
- `--motion-ease-enter` — кривая замедления;
- `--motion-stagger` и `--motion-stagger-max` — интервал и предел задержки;
- `--motion-press-scale` и `--motion-icon-shift` — отклик кнопок;
- `--motion-count-duration` — длительность числовых показателей.

`delay` у `Reveal` и `RevealHeading` задаёт редкое локальное исключение в секундах;
CSS ограничивает его общим пределом. Обычно достаточно токенов и группы.
`readCssMilliseconds` читает CSS-длительности с единицами `ms` и `s` для JavaScript. Новые зависимости не требуются.

## Доступность и производительность

Первый экран и восстановленная позиция прокрутки доступны сразу. Серверная
разметка остаётся видимой; скрытие применяется только после подключения
IntersectionObserver к блоку ниже экрана. При отсутствии API блок остаётся
статичным. Уже показанный блок сохраняет своё состояние при повторной прокрутке.

Фокус клавиатуры сразу раскрывает блок. Изменение `prefers-reduced-motion`
останавливает новые появления; CSS обеспечивает видимость также при печати.
Глобальный MotionConfig учитывает системную настройку в существующих
Motion-компонентах. Переход на другую страницу начинается сверху сразу;
внутренние плавные переходы используют настройку `scroll-behavior` из UI-kit.

Анимация появления меняет opacity и translate, сохраняя размеры элементов.
После окончания удаляется активное состояние анимации. Наблюдатели
отключаются; очистка также игнорирует ранее поставленные в очередь callbacks.
Canvas-орбиты останавливаются вне экрана и в скрытой вкладке, а при reduced motion
рисуются статично. Счётчики стартуют при появлении своих карточек; озвучивается
конечное значение, без промежуточных обновлений.

## Проверки

- `npm run lint`, `npm test`, `npm run build`.
- Тесты наблюдателя: первый экран, длинный блок, однократное появление, фокус,
  смена настройки движения и очистка при размонтировании.
- Серверные тесты: семантика заголовков, списков, ссылок и видимость текста.
- В Chromium: последовательность карточек, повторная прокрутка, клавиатура,
  печать, изменение reduced motion и остановка Canvas.
- Сравнение до/после для шести страниц на трёх ширинах: семейства, размеры,
  начертания, межстрочные интервалы, цвета, переносы и размеры заголовков совпали.

Каталог движения доступен в `/ui-kit` при запуске разработки.

Описание браузерных API: [Intersection Observer](https://developer.mozilla.org/en-US/docs/Web/API/Intersection_Observer_API),
[prefers-reduced-motion](https://developer.mozilla.org/en-US/docs/Web/CSS/@media/prefers-reduced-motion),
[MotionConfig](https://motion.dev/docs/react-motion-config).

Полный проход с анимациями дополнительно выявил существующий низкий контраст
надзаголовков и длительности в карточках `.tourism-package`: `--color-muted`
и `--color-trust` используются на фоне `--color-ink`. Эти правила в
`tourism-page.css` не менялись в данном задании: сохранение дизайна — явное
требование. В проверке axe эта существующая проблема учтена отдельно;
новых нарушений по проверенным правилам не обнаружено.

Итоговая браузерная проверка: 11 страниц × 4 ширины (320, 390, 768, 1440px),
без горизонтальной прокрутки, оставшихся скрытыми видимых блоков и ошибок
JavaScript. Отдельно проверены остановка Canvas и очистка кадров при переходе
по внутренней ссылке. Существующее горизонтальное смещение вступления на странице
врачей заменено общим появлением, поскольку оно вызывало переполнение на мобильном.

Контраст туристических пакетов, отмеченный в проверке FML-001, исправлен в FML-002
через существующие роли inverse; актуальные результаты: [аудит проекта](../../../docs/PROJECT_AUDIT_FML-002.md).
