# ТЕХНИЧЕСКОЕ ЗАДАНИЕ И СПЕЦИФИКАЦИЯ ДЛЯ АВТОТЕСТОВ И CI/CD
## Проект: Семейная стоматология «Family Dent» (г. Душанбе)

---

## 1. ВВЕДЕНИЕ И НАЗНАЧЕНИЕ ДОКУМЕНТА
Настоящий документ является **расширенным техническим заданием (ТЗ)** и **функциональной спецификацией** веб-приложения клиники **Family Dent**.  
Документ предназначен для:
- **Разработчиков** — как эталонная архитектурная и функциональная спецификация всех страниц, компонентов и пользовательских сценариев.
- **QA-инженеров и специалистов по автоматизации тестирования (AQA)** — для написания E2E-тестов (Playwright / Cypress), интеграционных тестов и Unit-тестов (Vitest / Jest).
- **DevOps / CI/CD инженеров** — для настройки автоматизированных проверок в пайплайне сборки перед деплоем.

---

## 2. ТЕХНОЛОГИЧЕСКИЙ СТЭК И АРХИТЕКТУРА
- **Фронтенд-фреймворк:** React 18+ (TypeScript), Vite
- **Стилизация и дизайн-система:** Tailwind CSS, кастомная система CSS-переменных (`--color-paper`, `--color-ink`, `--color-accent` и др.)
- **Анимации и жесты:** `motion/react` (Framer Motion)
- **Иконки:** `lucide-react`
- **Роутинг:** `react-router-dom`
- **Архитектура данных:** Одностраничное приложение (SPA) с модульной структурой данных в `/src/lib/data/*` и поддержкой модальных окон записи из любой точки сайта.

## 4. ПОДРОБНАЯ СПЕЦИФИКАЦИЯ РАЗДЕЛОВ И ТЕСТ-КЕЙСЫ (ACCEPTANCE CRITERIA)

### 4.1. ГЛОБАЛЬНЫЙ HEADER И FOOTER
#### Описание функциональности:
- **Header (`SiteHeader`)**: Закреплен сверху (`sticky top-0 z-40`), содержит логотип, ссылки на основные разделы, выпадающее меню «Пациентам» («Туризм», «Академия», «Отзывы», «Блог», «FAQ»), телефон для быстрой связи и кнопку «Записаться».
- **Footer (`SiteFooter`)**: Содержит блок локации с интерактивной картой (Душанбе, пр. Рудаки 45 / ул. Айни 45), контактные данные, график работы (Пн-Сб 08:00–20:00) и правовую информацию (Лицензия №12834-ТМ).

#### Сценарии автотестов (E2E / QA Checklist):
- [ ] **E2E-HDR-01**: При клике на логотип из любого раздела пользователь попадает на главную страницу `/`.
- [ ] **E2E-HDR-02**: При клике на кнопку «Записаться» в шапке открывается глобальное модальное окно бронирования (`BookingModal`).
- [ ] **E2E-HDR-03**: На мобильном разрешении (< 1024px) отображается кнопка-бургер; при нажатии открывается мобильное меню со всеми ссылками.
- [ ] **E2E-FTR-01**: В подвале отображается корректный телефон `+992 446 60 66 00` (или `+992 99 000-00-00`) с кликабельным `href="tel:..."`.

#### Описание функциональности:

  - Центральное интерактивное лого «Семья зубов» (`CentralLogo`), реагирующее на курсор/тач, с мягким свечением и анимацией SVG/3D-слоев.

#### Сценарии автотестов (E2E / QA Checklist):
- [ ] **E2E-HERO-01**: При загрузке страницы фоновое видео или резервный градиент рендерится без ошибок в консоли.
- [ ] **E2E-HERO-02**: Компонент `CentralLogo` корректно отображается на настольных и мобильных устройствах; SVG-контур не выходит за границы контейнера.
- [ ] **E2E-HERO-03**: Клик на кнопку «Записаться» в Hero-секции открывает модальное окно бронирования.

Демонстрация технологического парка клиники (`/about/equipment` + секция на главной).  
**Обязательное правило:** Каждая карточка аппарата содержит блок **«Что получает пациент?»** с понятной выгодой:
1. **Аксиограф** → *Что получает пациент:* Точное определение причины боли в суставе (ВНЧС), щелчков и правильный подбор высоты прикуса без переделок.
2. **Дентальный микроскоп (Leica/Zeiss)** → *Что получает пациент:* Лечение под 30-кратным увеличением: спасение сложных зубов, удаление скрытых обломков инструментов, сохранение здоровых тканей зуба.
3. **Компьютерный томограф (3D КТ)** → *Что получает пациент:* Полный 3D-снимок обеих челюстей за 14 секунд с дозой облучения ниже, чем при двухчасовом авиаперелёте; исключение ошибок в диагностике.
4. **Интраоральный 3D-сканер** → *Что получает пациент:* Цифровой слепок без неприятной слепочной массы во рту, без рвотного рефлекса и с мгновенной 3D-моделью будущей улыбки.
5. **Цифровая диагностика (AI & Smile Preview)** → *Что получает пациент:* Возможность увидеть свою будущую улыбку на экране ещё до начала протезирования или ортодонтии.
6. **Стерилизационное оборудование (Автоклавы класса B)** → *Что получает пациент:* 100% гарантия инфекционной безопасности и стерильности каждого инструмента, вскрываемого при пациенте.

#### Сценарии автотестов (E2E / QA Checklist):
- [ ] **E2E-EQP-01**: На странице оборудования представлены все 6 аппаратов: Аксиограф, Микроскоп, КТ, Сканер, Цифровая диагностика, Стерилизация.
- [ ] **E2E-EQP-02**: В DOM каждой карточки присутствует текст с ответом на вопрос *«Что получает пациент?»* (проверка селектора ответа).

4. **Художественная реставрация** (восстановление разрушенных кариесом зубов).
5. **Детская ортодонтия и терапия** (здоровое развитие улыбки ребенка).

#### Сценарии автотестов (E2E / QA Checklist):
- [ ] **E2E-RES-01**: Наличие кнопок фильтрации по 5 категориям: Виниры, Брекеты, Имплантация, Реставрация, Ортодонтия.

## 5. ТРЕБОВАНИЯ К CI/CD ПАЙПЛАЙНУ (AUTOMATION PIPELINE)

|  - npm run lint               |  <-- ESLint & TypeScript validation (tsc --noEmit)
+-------------------------------+

|  - npm test (Vitest)          |  <-- Проверка утилит, хелперов и данных врачей
+-------------------------------+
       |
       v
